CARA MENJALANKAN WEBSITE (PILIH SALAH SATU):
--------------------------------------------------------------------

OPSI 1: LANGSUNG KE FOLDER WAMP / XAMPP (DIREKOMENDASIKAN)
1. Copy seluruh folder "website" ini ke dalam folder web server Anda:
   - Pengguna WampServer : C:\wamp64\www\pasarmahasiswa\
   - Pengguna XAMPP       : C:\xampp\htdocs\pasarmahasiswa\
2. Nyalakan WampServer atau Apache di XAMPP Control Panel.
3. Buka browser (Chrome / Edge / Firefox) dan buka link berikut:
   http://localhost/pasarmahasiswa/

OPSI 2: LANGSUNG KLIK TANPA SERVER (OFFLINE BROWSER)
1. Masuk ke folder "website".
2. Klik 2x file "index.html".
3. Website akan langsung terbuka dan berjalan normal di browser Anda.
